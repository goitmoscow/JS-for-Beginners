# Переменные и константы JavaScript 📦

> **📚 Для кого этот материал:** Для новичков в программировании. Поймешь, как хранить и использовать данные в программе.
>
> **🎯 Что ты узнаешь:** Как создавать переменные, в чем разница между `let` и `const`, и как правильно их называть.
>
> **💡 Важно:** В примерах кода имена переменных написаны на английском языке (например: `name`, `age`, `user`). Это стандарт в программировании, которому нужно следовать с самого начала!

## 🎦 Что такое переменная?

Представь переменную как **коробку с этикеткой**:

📦 **Коробка** = место хранения данных  
🏷️ **Этикетка** = имя переменной  
💎 **Содержимое** = значение переменной

```javascript
let age; // Создали пустую коробку с этикеткой "возраст"
age = 25; // Положили в коробку число 25
```

## 🏷️ Три способа создать переменную

### 1️⃣ `let` — переменная с переназначением

```javascript
let name = "Иван"; // Создали и дали значение
console.log(name); // "Иван"

name = "Мария"; // ПОМЕНЯЛИ значение (можно!)
console.log(name); // "Мария"

let age; // Можно создать без значения
age = 30; // Потом добавить
```

### 2️⃣ `const` — без переназначения (по умолчанию)

```javascript
const PI = 3.14159; // Эту переменную нельзя переназначить
const BIRTH_YEAR = 1995;

// PI = 3; // ❌ ОШИБКА! Нельзя менять const
// BIRTH_YEAR = 1996; // ❌ ОШИБКА!

// Но ВНУТРИ объекта можно менять:
const person = {
  name: "Алекс",
  age: 25,
};

person.age = 26; // ✅ Можно! Меняем содержимое, не саму коробку
```

### 3️⃣ `var` — способ, встречающийся в существующем коде

```javascript
var oldVariable = "устаревший подход";
// В новом учебном коде предпочитаем const/let.
// var ограничен функцией, а обычный блок if не создаёт для него область.
```

## 🎯 Когда что использовать?

### 🟢 `const` — по умолчанию

```javascript
const USER_NAME = "admin"; // Не будет меняться
const API_URL = "https://api.site"; // URL сервера
const THEME_COLOR = "#2c3e50"; // Цвет дизайна
```

### 🟡 `let` - когда значение будет меняться

```javascript
let counter = 0; // Будем увеличивать
let user = null; // Потом загрузим с сервера
let currentPage = 1; // Будем переключать

counter++; // 1
counter++; // 2
currentPage = 5; // Поменяли
```

## 🏷️ Правила именования переменных

### ✅ ПОЗВОЛЕНО

```javascript
let name; // Русские буквы (но лучше английские)
let myName; // camelCase (рекомендуется)
let firstName; // Описательные названия
let user_age; // snake_case (тоже можно)
let user123; // Цифры в конце/середине
let $price; // $ в начале (для jQuery)
```

### ❌ ЗАПРЕЩЕНО

```javascript
let 1name;            // ❌ Не может начинаться с цифры
let user-name;        // ❌ Дефис не разрешен (используй _)
let var;              // ❌ Зарезервированное слово
let let;              // ❌ Зарезервированное слово
let class;            // ❌ Зарезервированное слово
```

## 💡 Лучшие практики именования

### 🎯 Описательные названия (хорошо)

```javascript
// ✅ ПРАВИЛЬНО
let userCount = 100;
let userAge = 25;
let isUserAuthenticated = true;

// ❌ НЕПРАВИЛЬНО
let x = 100; // Что такое x?
let a = 25; // Непонятно
let flag = true; // Какой флаг?
```

### 🎯 camelCase vs snake_case

```javascript
// camelCase (JavaScript стиль - РЕКОМЕНДУЕТСЯ)
let userName = "Вася";
let isLoggedIn = true;
let firstName = "Иван";

// snake_case (тоже работает, но менее популярный)
let user_name = "Вася";
let is_logged_in = true;
let first_name = "Иван";
```

### 🎯 Константы в ВЕРХНЕМ РЕГИСТРЕ

```javascript
const MAX_USERS = 1000;
const API_BASE_URL = "https://api.example.com";
const DEFAULT_TIMEOUT = 5000;
```

## 🔄 Область видимости (где видна переменная)

### 🏙️ Глобальная область (плохая практика)

```javascript
let globalVariable = "Вижу везде";

function myFunction() {
  console.log(globalVariable); // ✅ Вижу
}

myFunction();
console.log(globalVariable); // ✅ Вижу
```

### 🏠 Локальная область (хорошая практика)

```javascript
function myFunction() {
  let localVariable = "Вижу только внутри";
  console.log(localVariable); // ✅ Вижу
}

myFunction();
console.log(localVariable); // ❌ ОШИБКА! Не вижу
```

### 🏢 Блочная область (в фигурных скобках {})

```javascript
if (true) {
  let blockVariable = "Вижу только в {}";
  console.log(blockVariable); // ✅ Вижу
}

console.log(blockVariable); // ❌ ОШИБКА! Не вижу
```

let и const имеют блочную область видимости. var ограничен функцией и виден за пределами обычного блока if. Объявление var обрабатывается заранее: до строки объявления значение равно undefined. Для let/const доступ до инициализации запрещён (TDZ) и вызывает ReferenceError. Объявляйте переменные до использования.

## 🚨 Частые ошибки новичков

### ❌ Использование до объявления

```javascript
console.log(name); // ❌ ReferenceError (ошибка!)
let name = "Вася";

console.log(age); // ❌ ReferenceError (ошибка!)
const age = 25;
```

### ❌ Повторное объявление

```javascript
let x = 5;
let x = 10; // ❌ SyntaxError - нельзя объявлять дважды

const y = 5;
const y = 10; // ❌ SyntaxError
```

### ❌ Попытка изменить const

```javascript
const PI = 3.14;
PI = 3; // ❌ TypeError - нельзя менять const
```

## 🎯 Практические примеры

### 📊 Счетчик

```javascript
let clicks = 0; // Начальное значение

function countClicks() {
  clicks++; // Увеличиваем на 1
  console.log(`Кликов: ${clicks}`);
}

countClicks(); // Кликов: 1
countClicks(); // Кликов: 2
countClicks(); // Кликов: 3
```

### 👤 Профиль пользователя

```javascript
const name = "Елена"; // Не меняется
const birthDate = "1990-01-15"; // Не меняется

let age = 34; // Будет меняться каждый год
let city = "Москва"; // Может переехать

console.log(`${name}, ${age} лет, живет в ${city}`);

age = 35; // Прошел год
city = "Санкт-Петербург"; // Переехала

console.log(`${name}, ${age} лет, живет в ${city}`);
```

### 🎮 Игровые переменные

```javascript
const GAME_NAME = "Космические приключения";
const MAX_HEALTH = 100;

let currentHealth = 100;
let livesCount = 3;
let level = 1;
let score = 0;

// В процессе игры:
currentHealth -= 10; // Получил урон
score += 100; // Набрал очки
level++; // Перешел на новый уровень
```

## 📚 Шпаргалка быстрого выбора

| Что храним?                        | Что использовать?         | Пример                        |
| ---------------------------------- | ------------------------- | ----------------------------- |
| Постоянные значения (конфиги)      | `const`                   | `const API_URL = "...";`      |
| Данные, которые не должны меняться | `const`                   | `const userId = 123;`         |
| Счетчики, флаги                    | `let`                     | `let counter = 0;`            |
| Данные из API                      | `const` (если не меняешь) | `const user = api.getUser();` |
| Промежуточное значение без переназначения | `const` | `const total = a + b;` |

## 🎮 Практика в консоли

Открой F12 и попробуй:

```javascript
// Создай разные переменные
let age = 25;
const name = "Ты";
let score = 0;

// Измени let переменные
age++;
score += 100;

// Попробуй изменить const (ошибка!)
// name = "Другое имя"; // Раскомментируй для проверки ошибки

// Создай массив и меняй его
const fruits = ["яблоко", "банан"];
fruits.push("апельсин"); // Можно!
console.log(fruits);
```
