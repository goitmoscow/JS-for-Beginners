## 🎯 Как учиться эффективно

### ✅ Правильный подход:

1. **Читай по порядку** - не перепрыгивай темы
2. **Практикуй сразу** - открывай консоль (F12) и пробуй код
3. **Экспериментируй** - меняй примеры и смотри что получится
4. **Делай заметки** - записывай главное своими словами
5. **Не спеши** - лучше понять медленно, чем быстро забыть

### 💡 Советы новичкам:

- **Все имена переменных в коде на английском** - это стандарт в программировании
- **Не пытайся запомнить всё** - программисты постоянно подсматривают в документацию
- **Ошибки - это нормально** - каждый программист постоянно ошибается
- **Google - твой друг** - не стесняйся искать ответы

## Как запускать примеры

Блоки кода внутри раздела могут продолжать предыдущий пример. При повторном запуске const/let в консоли очистите контекст или используйте отдельный блок { ... }. Примеры с ❌ намеренно содержат ошибки; бесконечные циклы не запускайте.

Для DOM, событий, localStorage и alert нужен браузер. Node.js подходит для вычислений и чистых функций; document и window в нём отсутствуют. Фрагменты с /api/... требуют вашего сервера, а учебные запросы к JSONPlaceholder зависят от сети. Для браузерной практики используйте собственную HTML-страницу.

## Как работает GitHub Pages

Страницы формирует в браузере Docsify 5.1.0. Используются официальные Core/Core Dark темы и плагин поиска той же версии. Подсветка JavaScript и HTML встроена в Docsify; дополнительные грамматики TypeScript и Java подключены из Prism 1.30.0. CDN-адреса закреплены на конкретные версии.

Светлая и тёмная темы переключаются кнопкой; выбор сохраняется в браузере. До первого выбора используется тема системы. Для обновления версии одновременно меняйте CSS, основной скрипт и плагин поиска в `index.html`, затем проверяйте навигацию, поиск, таблицы и подсветку.

Сборка и npm-зависимости для публикации не требуются. Для локального просмотра из папки репозитория достаточно запустить `python3 -m http.server 8000` и открыть http://localhost:8000. Подключение библиотек через CDN требует доступа к сети.

Официальные инструкции: [переход на Docsify 5](https://docsify.js.org/#/v5-upgrade), [темы](https://docsify.js.org/#/themes).

## 📖 Словарь начинающего

- **Переменная** - "коробка" для хранения данных
- **Функция** - набор инструкций, который можно вызвать
- **Метод** - функция, которая принадлежит объекту
- **Аргумент/параметр** - данные, которые передаем в функцию
- **Возвращаемое значение** - результат работы функции
- **Итерация** - один проход цикла
- **Callback** - функция, переданная как аргумент
