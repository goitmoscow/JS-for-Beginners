## 📖 История JavaScript

JavaScript появился в **1995 году**. Первый прототип Брендан Айк написал примерно за **10 дней**, а затем язык развивался десятилетиями.

### 🎬 Как всё начиналось:

**Брендан Айк** (Brendan Eich) работал в компании **Netscape** — разработчики браузера Netscape Navigator. Разработчикам нужен был язык для программируемого поведения непосредственно в браузере. Айку дали задание сделать язык программирования, чтобы страницы стали живыми и интерактивными.

Изначально язык назвали **Mocha**, потом переименовали в **LiveScript**, а перед самым релизом — в **JavaScript**, чтобы привлечь внимание разработчиков на Java. При этом JavaScript и Java — совершенно разные языки, общего у них не больше, чем у слов «кар» и «карамель».

### 🚀 Эволюция языка:

| Год | Событие | Что изменилось |
|-----|---------|---------------|
| **1995** | Рождение JavaScript | Брендан Айк создаёт язык в Netscape |
| **1996** | Война браузеров | Microsoft создаёт свою версию — JScript для Internet Explorer |
| **1997** | Стандарт ECMAScript (ES1) | Язык стандартизирован, чтобы работать одинаково во всех браузерах |
| **2005** | Популяризация AJAX | Распространилось обновление части страницы без перезагрузки |
| **2006** | jQuery | Библиотека, которая упростила работу с JS в разы |
| **2009** | Node.js + ES5 | JS вышел за пределы браузера, появился Node.js для серверов |
| **2010** | AngularJS | Один из инструментов разработки одностраничных приложений |
| **2013** | React | Публичный выпуск библиотеки для пользовательских интерфейсов |
| **2014** | Vue.js | Эван Ю создаёт Vue — простой и гибкий фреймворк |
| **2015** | ES6/ES2015 | Революция! Классы, стрелочные функции, промисы, модули |
| **2017** | async/await | Асинхронный код стал простым и читаемым |
| **2020+** | Deno, Bun | Развитие альтернативных сред выполнения JavaScript |
| **С 2015** | Ежегодные редакции ECMAScript | Язык продолжает получать новые возможности |

### 🤯 Интересные факты:

- Со времени появления JS прошёл путь от простых скриптов до языка, на котором пишут **всё**: сайты, серверы, мобильные и десктопные приложения, игры, нейросети
- JavaScript используется в браузерах и серверных средах; конкретные рейтинги популярности зависят от года и методики
- npm — реестр пакетов и инструмент для управления зависимостями JavaScript-проектов
- SpaceX использует JavaScript в интерфейсе управления кораблём Dragon 🚀

## 🤔 Роль JavaScript в вебе

Представь, что веб-сайт — это дом:

🏗️ **HTML** = стены, окна, фундамент (структура)
🎨 **CSS** = обои, мебель, цвет (красота)
⚡ **JavaScript** = электричество, розетки, кнопки (жизнь)

HTML уже позволяет переходить по ссылкам и отправлять формы, CSS — оформлять страницу и добавлять анимацию. JavaScript нужен для программируемого поведения: обработки событий, работы с данными и обновления интерфейса.

## 💡 Как запустить JavaScript?

### 🖥️ Способ 1: В консоли браузера

1. Открой любой сайт
2. Нажми F12
3. Перейди в "Console"
4. Пиши код и жми Enter

```javascript
alert("Привет мир!"); // ← Попробуй!
```

### 📄 Способ 2: HTML файл

Создай файл `index.html`:

```html
<!DOCTYPE html>
<html>
  <body>
    <h1>Мой первый JS</h1>
    <button onclick="alert('Клик!')">Нажми меня</button>

    <script>
      console.log("Сайт загружен!");
    </script>
  </body>
</html>
```

## 🛡️ Безопасность JavaScript в браузере

В браузере JS работает в «песочнице» — изолированной среде с ограничениями:

### ✅ Что МОЖЕТ делать JS в браузере:

- Менять содержимое страницы
- Работать с формами
- Показывать/скрывать элементы
- Отправлять запросы на сервер
- Сохранять данные в браузере (localStorage, cookies)

### ❌ Что НЕ МОЖЕТ делать JS в браузере:

- Читать файлы с компьютера (без разрешения пользователя)
- Прямо обращаться к базе данных
- Удалять файлы пользователя
- Получать доступ к другим вкладкам и сайтам

> **Важно:** эти ограничения действуют только в браузере. На сервере (Node.js) JavaScript имеет полный доступ к файловой системе, базам данных и сети — как любой другой серверный язык.
