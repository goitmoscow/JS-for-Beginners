# Типы данных JavaScript 🧰

> **📚 Для кого этот материал:** Для тех, кто хочет понять, какие типы данных существуют в JavaScript.
>
> **🎯 Что ты узнаешь:** Какие бывают типы данных (числа, строки, boolean и др.) и как с ними работать.
>
> **💡 Важно:** В примерах кода имена переменных написаны на английском языке (например: `name`, `age`, `user`). Это стандарт в программировании!

## 🎦 Что такое "тип данных"?

Представь типы данных как **разные коробки** для разных вещей:

📦 **Коробка для цифр** = храним числа  
📦 **Коробка для текста** = храним буквы  
📦 **Коробка для флажков** = храним да/нет

Тип принадлежит значению. Объявление let может получать значения разных типов; const запрещает переназначение. Всего типов восемь: семь примитивных и object.

## 🎯 Простые типы данных (примитивы)

### 1️⃣ Числа (Number) 🔢

```javascript
let age = 25; // Целое число
let price = 99.99; // Дробное число
let negativeNum = -10; // Отрицательное число

// Математика работает как калькулятор
let sum = age + 5; // 30
let product = 6 * 7; // 42
```

### 2️⃣ Строки (String) 📝

```javascript
let name = "Иван"; // В двойных кавычках
let city = 'Москва'; // В одинарных кавычках
let greeting = `Привет!`; // В обратных кавычках (мощнее!)

// Сложение строк = склеивание
let fullName = name + " Петров"; // "Иван Петров"
let ageStatus = "Мне " + age + " лет"; // "Мне 25 лет"

// Мощь обратных кавычек:
let autoGreeting = `Привет, ${name}! Тебе ${age} лет.`;
// Результат: "Привет, Иван! Тебе 25 лет."
```

### 3️⃣ Булев тип (Boolean) ✅❌

Только ДВА значения: `true` (да) или `false` (нет)

```javascript
let isAdult = true; // Да, совершеннолетний
let isUnemployed = false; // Нет, не безработный

// Сравнения дают Boolean
let x = 5;
let y = 10;

let xGreaterThanY = x > y; // false (5 не больше 10)
let xLessThanY = x < y; // true (5 меньше 10)
let areEqual = x == y; // false (5 не равно 10)
```

### 4️⃣ Undefined (не определено) ❓

```javascript
let myVariable; // Объявили, но не дали значение
console.log(myVariable); // undefined

// Типа: "Я знаю про эту коробку, но она пустая"
```

### 5️⃣ Null (пусто) 📦

```javascript
let phone = null; // Явно сказали: "телефона нет"

// Типа: "Это специальная пустая коробка с надписью 'ПУСТО'"
```

### 6️⃣ Symbol (символ) 🔑

```javascript
let id = Symbol("uniqueKey");
// Очень редкий тип, нужен для уникальных идентификаторов
```

### 7️⃣ BigInt — большие целые числа

```javascript
const exact = 9007199254740993n;
console.log(typeof exact); // "bigint"
console.log(exact + 2n); // 9007199254740995n
// exact + 2 вызовет TypeError: BigInt и Number нельзя смешивать в арифметике.
```

## 🏰 Объектный тип: object

Массив и функция — разновидности объектов, а не дополнительные типы языка. У функции typeof возвращает "function", у массива — "object".

Сложные типы ещё называют **ссылочными** — и это важно понимать.

**Примитивные значения неизменяемы**. Когда ты копируешь примитив — создаётся независимая копия:

```javascript
let a = 10;
let b = a; // b получил копию значения
b = 20;
console.log(a); // 10 (не изменилось!)
```

**Ссылочные типы** (объекты, массивы, функции) хранят не сами данные, а **ссылку** (адрес) на них в памяти. Когда копируешь — копируется только ссылка, а данные общие:

```javascript
let original = { name: "Анна", age: 25 };
let copy = original; // copy указывает на тот же объект!
copy.age = 30;
console.log(original.age); // 30 (изменился и оригинал!)
```

Представь это как **адрес дома**: если два человека записали один и тот же адрес, они придут в один и тот же дом. Перекрасил стену один — увидят оба.

```javascript
// То же самое с массивами
let fruits = ["яблоко", "банан"];
let myFruits = fruits; // та же ссылка
myFruits.push("апельсин");
console.log(fruits); // ["яблоко", "банан", "апельсин"] (изменился!)

// Чтобы создать независимую копию:
let realCopy = [...fruits]; // поверхностная копия через spread
realCopy.push("манго");
console.log(fruits.length);   // 3 (не изменился)
console.log(realCopy.length); // 4
```

Копия через spread независима только на верхнем уровне: вложенные объекты остаются общими ссылками.

### 🏠 Объект (Object)

```javascript
// Объект = контейнер с данными
let person = {
  name: "Мария",
  age: 30,
  city: "Санкт-Петербург",
};

// Доступ к данным
console.log(person.name); // "Мария"
console.log(person["age"]); // 30
```

### 📋 Массив (Array)

```javascript
let fruits = ["яблоко", "банан", "апельсин"];
let numbers = [1, 2, 3, 4, 5];

// Доступ по номеру (индекс начинается с 0!)
console.log(fruits[0]); // "яблоко"
console.log(fruits[1]); // "банан"
```

## 🔍 Как узнать тип данных?

### Оператор `typeof`

```javascript
typeof 42; // "number"
typeof "привет"; // "string"
typeof true; // "boolean"
typeof undefined; // "undefined"
typeof null; // "object" (историческая ошибка JS!)
typeof []; // "object"
typeof {}; // "object"

// Проверка на массив по-другому:
Array.isArray([]); // true
Array.isArray({}); // false
```

## 🎭 Динамическая vs статическая типизация

### 🔄 Динамическая типизация (JavaScript)

В JavaScript переменной let можно присваивать значения разных типов — это называется **динамическая типизация**. Ты не указываешь тип при создании переменной, и в одну переменную можно положить сначала число, потом строку:

```javascript
let variable = 42; // Сначала число
console.log(typeof variable); // "number"

variable = "сорок два"; // Теперь строка!
console.log(typeof variable); // "string"

variable = true; // Теперь булев!
console.log(typeof variable); // "boolean"
```

Это удобно и быстро, но может приводить к неожиданным ошибкам — ты ожидаешь число, а в переменной строка.

### 🔒 Статическая типизация (другие языки)

В **статически типизированных** языках тип переменной задаётся один раз и не может меняться. Если переменная создана как число — в неё нельзя положить строку:

```java
// Java — статическая типизация
int age = 25;       // Только число
age = "двадцать";   // Ошибка компиляции!

String name = "Иван"; // Только строка
name = 42;             // Ошибка компиляции!
```

| | Динамическая | Статическая |
|---|---|---|
| **Тип задаётся** | Принадлежит значению | Явно или выводится компилятором |
| **Можно менять тип?** | Да, в любой момент | Нет, ошибка компиляции |
| **Ошибки типов** | Обнаруживаются при запуске | Обнаруживаются до запуска |
| **Языки** | JavaScript, Python, Ruby | Java, C#, Go, Rust |
| **Плюс** | Гибкость, скорость написания | Надёжность, меньше багов |

### 🟦 TypeScript — лучшее из двух миров

**TypeScript** — это JavaScript с добавлением статических типов. Его создал Microsoft в 2012 году, он добавляет проверку типов перед выполнением.

```typescript
// TypeScript — тип можно указать явно или дать компилятору вывести его
let age: number = 25;
age = "двадцать"; // Ошибка! Тип 'string' нельзя присвоить типу 'number'

let name: string = "Иван";
let isAdmin: boolean = false;

function greet(user: string): string {
  return `Привет, ${user}!`;
}

greet("Анна");  // OK
greet(42);      // Ошибка! Ожидается string, а не number
```

**Зачем нужен TypeScript:**

- Ловит ошибки типов **до запуска** программы, прямо в редакторе
- Подсказки в VS Code — автодополнение работает гораздо лучше
- Код легче читать — видно, какие данные ожидает функция
- TypeScript компилируется в обычный JavaScript, поэтому работает везде

> **Для новичка:** сначала изучи JavaScript, а когда будешь уверенно писать код — переходи на TypeScript. Это будет легко, потому что TypeScript — это тот же JS, только с типами.

## 🔄 Преобразование типов

### 📝 В строку (String)

```javascript
String(123); // "123"
String(true); // "true"
String(null); // "null"

// Или с помощью сложения
let number = 42;
let toString = number + ""; // "42"
```

### 🔢 В число (Number)

```javascript
Number("123"); // 123
Number("123.45"); // 123.45
Number(true); // 1
Number(false); // 0
Number(""); // 0

// Специальные способы
parseInt("25 лет", 10); // 25: числовой префикс, основание 10
parseFloat("12.5 кг"); // 12.5 (дробное)
```

### ✅ В булев (Boolean)

```javascript
Boolean(1); // true
Boolean(0); // false
Boolean("привет"); // true
Boolean(""); // false (пустая строка = ложь)
Boolean(null); // false
Boolean(undefined); // false

// Быстрый способ с !!
!!"привет"; // true
!!0; // false
```

## 🚨 Частые ошибки новичка

### ❌ Сравнение `==` vs `===`

```javascript
5 == "5"; // true  (преобразует типы)
5 === "5"; // false (строгое сравнение без преобразования)

null == undefined; // true
null === undefined; // false

// Рекомендация: ВСЕГДА используй === для сравнения!
```

### ❌ Сложение строк и чисел

```javascript
"5" + 3; // "53" (склеивание!)
5 + "3"; // "53" (тоже склеивание!)

5 + 3 + "7"; // "87" (5+3=8, потом 8+"7")
"5" + 3 + 7; // "537" (все в строки!)

// Решение: явно преобразовывай в числа
Number("5") + 3; // 8
```

### ❌ NaN (Not a Number)

```javascript
Number("привет"); // NaN (Не-число)

// Проверка на NaN
Number.isNaN(NaN); // true
Number.isNaN(123); // false
Number.isNaN("текст"); // false: строка не является значением NaN
isNaN("текст"); // true: глобальная isNaN сначала преобразует строку в число
Number.isFinite(Infinity); // false: проверка конечного числа
```

## 🎯 Шпаргалка-сводка

| Тип данных    | Пример               | Когда использовать                   |
| ------------- | -------------------- | ------------------------------------ |
| **Number**    | `25`, `99.99`        | Для математики, возрастов, цен       |
| **String**    | `"текст"`, `'слово'` | Имена, сообщения, адреса             |
| **Boolean**   | `true`, `false`      | Флажки, условия, проверки            |
| **Undefined** | `let x;`             | Когда переменная объявлена, но пуста |
| **Null**      | `null`               | Когда явно нужно сказать "пусто"     |
| **Object**    | `{name: "Вася"}`     | Комплексы данных, профили            |
| **BigInt** | `42n` | Целые числа вне безопасного диапазона Number |
| **Symbol** | `Symbol("id")` | Уникальные ключи |

Массив `[1, 2, 3]` имеет тип object. Функция тоже объект; особый результат typeof для неё — "function".
